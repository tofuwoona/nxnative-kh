# KH2 combined diagnostic / aspect build — handoff

Branch `diag/kh2-save-aspect-combined` starts from `feature/aspect-ratio-unlock` (which includes `fix/kh2-save-backslash-path` and its KH1 extension) and merges `diag/kh2-continuous-save-metal-logging`. KH2's `host_path_ex` still maps both guest spellings of the save to the canonical slash tree; KH1's same prefix is also handled. The separate `kh2_save_migrate` legacy-copy helper remains gated by `DM_KH2_SAVE_FIX_MIGRATE=1` and **is not enabled** in this diagnostic build.

The iOS launcher exposes `Fill screen (crop)` (`DM_ASPECT_FILL`, default `0`) only for the KH1/KH2 direct profiles. It is a crop of an internally 16:9 frame, not a true engine widescreen unlock; edge HUD may be cut off. `DM_KH24_DIAG=1` is bundled for the KH2 diagnostic build, enabling save-operation and Vulkan-to-Metal pass logging with two rotating log segments (`Documents/log.txt`, `log.prev.txt`). The diagnostic pass/pipeline trace is high-volume and may itself affect performance; avoid comparing its FPS to an uninstrumented build as if matched.
